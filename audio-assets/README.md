# Shotbase Audio Assets

Download target folders:

- `music/hype`
- `music/clean`
- `music/roundup`
- `music/authority`
- `sfx`

Uppbeat blocks direct command-line downloads and requires a logged-in browser session to generate the licensed download URL/auth token. After logging in, use `audio-assets/manifest.md` as the checklist and save files into these folders.
